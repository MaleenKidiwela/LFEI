MTJ dv/v model

One joint model for every measured seismic velocity change: dv/v at each station = Σ amplitude × driver(t), with drivers for rain and groundwater, the 2021, 2022 and 2024 earthquakes and the post-2021 change, fitted to all data at once. The data resolve changes beneath each station in the top few kilometres, so the map shows dv/v interpolated over a correlation length estimated from the data, faded where the data constrain it poorly, with each station's own value on top; below about 3 km the model gives a bound, not a map. Amplitudes are apparent: the coda coupling is uncertain by a factor of 2.5–10, so both calibrations are shown. Blue is faster, red is slower.
